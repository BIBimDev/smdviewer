## Verified results and review boundary

**Sample-verified:** plain column retains 8 vertices/6 faces and its transform;
pocket column retains 16 vertices/10 faces with absent transform. Both retain
transformed bounds X `-375..375`, Y `-325..325`, Z `-1000..5000` mm. Local vertex
coordinates, source planes, face loops, source identities and all returned TS
metadata match their goldens. No placement composition or geometric reinterpretation
is performed. `verticesWorld` only describes the detected B-rep transform result.

**Intentional deviations/boundaries:** C++ strings are validated UTF-8; ill-formed
byte sequences are explicitly rejected and lone UTF-16 surrogates are outside this
native text interface. Malformed, impossibly large profile counts may return the
same empty array earlier than TS. JSON v1 adopts TS optional-field omission and
non-finite-to-null semantics; finite serialization is deterministic but not byte
identical to TS number formatting. No other intentional semantic change is made.

**Inferred/unknown:** the format is specimen-derived, with no authoritative DICAD
specification. General metadata offsets, global placement, arbitrary encodings,
topological validity, other object classes and subject selection remain unverified.
The reference's permissive header handling, first-valid-candidate scanning across
the geometry tail, optional-data fallbacks, and some non-finite acceptance are
deliberately retained and documented/tested. They are not stronger format guarantees.

Team review is needed to accept the proposed JSON v1 contract, UTF-8 boundary and
retained reference quirks, and to arrange MSVC verification. No SQLite, normalization,
feature recognition, Boolean/engineering work, C ABI, WebAssembly or BI301 selection
is included. Stop at the reviewable GEO-00 PR; do not merge or begin GEO-01.
